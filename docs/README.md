## Установка и запуск

### Требования
- Docker & Docker Compose
- Node.js 18+ (для разработки)

### Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository>
   cd bot-platform
   ```

2. **Настройте окружение:**
   ```bash
   cp .env.example .env
   # Отредактируйте .env - добавьте токены и настройки
   ```

3. **Запустите платформу:**
   ```bash
   docker compose up -d
   ```

4. **Откройте UI:**
   ```
   http://localhost:3000
   ```

## Создание первого бота

### 1. Войдите через Telegram
Используйте Telegram Login Widget для авторизации.

### 2. Создайте бота
- Нажмите "Create bot"
- Укажите имя и код бота
- Выберите runtime (Docker/Swarm/K8s)
- Укажите путь к исходникам:
  - **Local:** `./packages/sample-bot`
  - **Git:** `https://github.com/user/my-bot.git`
  - **Zip:** `/path/to/bot.zip`
- Добавьте BOT_TOKEN от @BotFather

### 3. Запустите бота
- Нажмите кнопку "▶" в карточке бота
- Бот автоматически развернётся и зарегистрирует webhook

```
┌─────────────────┐
│    Web UI       │  ← Пользовательский интерфейс
└────────┬────────┘
         │
┌────────▼────────┐

└────────┬────────┘
         │
    ┌────┴────┬────────┬────────┐
    │         │        │        │
┌───▼───┐ ┌──▼──┐ ┌───▼──┐ ┌───▼───┐
│ Bot 1 │ │Bot 2│ │Bot 3 │ │Bot N  │  ← Изолированные контейнеры
└───┬───┘ └──┬──┘ └───┬──┘ └───┬───┘
    │        │        │        │

│   Telegram Bot API (local)       │  ← Локальный Bot API сервер
└──────────────────────────────────┘
```

### Компоненты

- **Bot Manager** - Центральный сервис управления
  - REST API для создания/управления ботами
  - Деплой в Docker/Swarm/K8s
  - Управление БД и изоляцией
  - Сбор логов

- **Bot SDK** - Библиотека для разработки ботов
  - Логирование с отправкой в manager
  - Доступ к изолированной БД
  - Конфигурация и env переменные

- **Web UI** - Интерфейс управления
  - Создание и настройка ботов
  - Мониторинг статуса
  - Просмотр логов
  - Управление env переменными

- **Runtime Adapters** - Адаптеры для деплоя
  - Docker (single container)
  - Docker Swarm
  - Kubernetes

## Особенности

### 🔒 Изоляция и безопасность
- Каждый бот в отдельном контейнере
- Изолированная БД для каждого бота:
  - **SQLite:** отдельный файл `bot.db`
  - **PostgreSQL:** отдельная схема + пользователь
- Токены не попадают в логи

### 📊 Централизованное логирование
- Логи автоматически отправляются в manager
- Хранятся в БД
- Доступны в UI
- Цветной вывод в консоли

### ⚙️ Управление конфигурацией
- Манифест бота определяет разрешённые env
- Whitelist подход - только указанные переменные
- Удобные имена через `configKey`
- Валидация на уровне платформы

### 🚀 Простой деплой
- Поддержка git, zip, local path
- Автоматическая сборка Docker образов
- Webhook регистрация
- Update и restart без даунтайма
